# Rahul Patra – Portfolio
React + Vite + Three.js (react-three-fiber).

    npm install
    npm run dev       # local dev server
    npm run build     # production build in /dist

- Replace `public/photo.png` with your own transparent-background PNG (portrait works best).
- Edit content (skills, jobs, projects, links) at the top of `src/App.jsx`.
- Greetings: `G` array at the top of `src/App.jsx`.
- 3D models live in `src/Models.jsx`.
